# 🚨 ResQMesh

### Resilient Emergency Communication System

> **When the network fails, the network becomes us.**

ResQMesh is a prototype emergency communication platform designed to help people communicate during disasters when conventional connectivity may be unavailable.

## 🎯 Problem

During floods, earthquakes, cyclones, fires and other disasters, communication infrastructure can become unavailable or overloaded.

People may be unable to reach rescue teams through conventional communication channels.

## 💡 Solution

ResQMesh explores a resilient communication model where nearby devices can act as communication nodes and relay emergency messages toward responders.

The system provides:

- Emergency reporting
- Emergency type selection
- Location capture
- Priority scoring
- Emergency dashboard
- Alert management
- Mesh network visualization
- Local browser storage
- Mobile responsive interface

## 🧠 Smart Priority Engine

The prototype calculates an emergency priority score using:

- Emergency type
- Number of people
- Location availability

The system categorizes alerts into:

- 🔴 Critical
- 🟠 High
- 🟡 Medium
- 🟢 Low
